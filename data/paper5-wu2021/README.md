# Wu et al. 2021 data

This directory contains the processed breast cancer single-cell data and public
analysis code for Paper 5 (Wu et al., *Nature Genetics*, 2021).

## Contents

- `GSE176078_Wu_etal_2021_BRCA_scRNASeq.tar.gz`: original processed GEO bundle
- `GEO/Wu_etal_2021_BRCA_scRNASeq/`: extracted count matrix, gene and barcode
  tables, and sample/cell metadata
- `BrCa_cell_atlas/`: public code repository from the Swarbrick lab

## Sources

- GEO: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE176078
- Analysis repository: https://github.com/Swarbricklab-code/BrCa_cell_atlas
- Paper: https://doi.org/10.1038/s41588-021-00911-1
